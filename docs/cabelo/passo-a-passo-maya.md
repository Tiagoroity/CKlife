# Passo a passo “Maya” — 49 folhas (5 rodadas)

Como fazer:
1. Em cada rodada, cole o **bloco inteiro** (estilo + 10 folhas) no gerador. Ele cria 10 imagens.
2. Mande as imagens aqui no chat do CK Life **com o número da folha** (ou na ordem). Eu recorto as 9 fotos de cada folha, confiro e devolvo os arquivos com nome certo.
3. No painel: Conteúdo → Cabelo para Treinar → **Enviar miniaturas em lote** → selecione todos os arquivos. Cada foto vai para o passo certo do penteado certo.
