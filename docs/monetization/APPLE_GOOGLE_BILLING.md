# Apple e Google

A tabela `assinaturas` já aceita `provider` = `apple` e `google`, e todos geram o mesmo entitlement CK_LIFE_PRO.
Quando o app for para as lojas: compras dentro do app pelo sistema de cobrança de cada loja (StoreKit / Google Play Billing), com validação no servidor (App Store Server Notifications / Real-time Developer Notifications) gravando em `assinaturas`. O checkout Kiwify não deve aparecer nas versões das lojas.
Pendente: IDs de produto da Apple e do Google.
